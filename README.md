# 👤 My Card

A responsive personal profile card built using HTML, CSS, and JavaScript.

## 📌 Overview

This project showcases a modern and responsive personal profile card with a clean user interface. It was created to practice front-end development fundamentals and responsive web design.

## ✨ Features

- Responsive design
- Modern user interface
- Interactive elements
- Clean layout
- Mobile-friendly

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## 📚 Skills Demonstrated

- Responsive Web Design
- CSS Flexbox
- UI Design
- DOM Manipulation
- Clean Code Structure

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/bahar-gh1380/my-card.git
```

Open **index.html** in your browser.
